Cameo - independent Android mobile and TV preview

Standalone app made by Mark Mateo. Based on the original POV Kodi add-on by kodifitzwell.

Original POV visual identity and fanart: kodifitzwell, sourced from POV 6.10.06 at https://github.com/kodifitzwell/repo (revision 2ea2eb7f330988ade16d388d3832b8e4b60c6b24). The upstream add-on manifest declares GNU GPL version 3. The original author is not affiliated with this Android port. Cameo 0.4 adds original native vector launcher marks and TV banners; retained POV assets and historical concepts remain attributed to their sources.

The retained POV wordmark is a generated cutout based on the earlier selected POV icon. The six October 26, 2026 design-preview images are historical generated concepts using the same POV visual identity. They are not screenshots of the running application. Cameo's current appearance picker renders native palette previews separately.

The new Android application source is provided under GNU GPL version 3. The accompanying source distribution includes the license text. Original assets are retained with their attribution. No upstream default application credentials are included in this application.
