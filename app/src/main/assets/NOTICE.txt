POV Standalone - independent Android TV port preview

Standalone app made by Mark Mateo. Based on the original POV Kodi add-on by kodifitzwell.

POV visual identity and original fanart: kodifitzwell, sourced from POV 6.10.06 at https://github.com/kodifitzwell/repo (revision 2ea2eb7f330988ade16d388d3832b8e4b60c6b24). The selected launcher icon is generated design concept 3, created using the original POV icon as its reference. The upstream add-on manifest declares GNU GPL version 3. The original author is not affiliated with this Android port.

The transparent in-app POV wordmark is a generated cutout based on that selected icon. The six October 26, 2026 design-preview images are generated concepts using the same POV visual identity. They are picker references, not screenshots of the running application; the interface renders native controls and live catalog artwork separately.
