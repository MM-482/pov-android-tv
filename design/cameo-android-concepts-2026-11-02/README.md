# Cameo Android TV — five theme concepts

Created November 2, 2026 with the built-in image generation tool for the proposed POV-to-Cameo Android TV rebrand.

These are visual concepts, not implemented screens or a new APK. Movie titles, artwork, and viewing progress are illustrative. There is no personal login information or connected service state in the images or gallery.

Open `index.html` in a browser to compare all five. The gallery uses only local assets and works without a server or internet connection. Select a preview to open a larger view; use Left/Right to compare and Escape to close it.

| # | Theme | Direction |
|---|---|---|
| 1 | Glass | Cool blue glass sidebar and an immersive cinematic backdrop |
| 2 | Cinema | Matte black, champagne highlights, top navigation and dramatic titles |
| 3 | Slate | Practical graphite sidebar, compact feature panel and emerald focus |
| 4 | Pearl | Light ivory gallery, editorial serif typography and a split hero |
| 5 | Aurora | Midnight violet, subtle teal glow and a floating navigation capsule |

Each image is 1672 × 941 pixels, approximately 16:9. Each keeps the familiar Home, Movies, Shows, Anime, Library, Search, and Settings destinations, a featured title, Continue Watching, and a discovery shelf. The intended focused action is Explore.

`assets.json` records the deliverables and intended palettes. `prompts.json` records the generation brief and the theme prompt specifications. Small differences in fictional poster artwork are part of the generated studies, rather than app behavior.

The current Android application, existing APK, package identity, account storage, GitHub repository and published announcements were not changed by this concept task. Feature parity with the Windows and Mac versions is a later discussion.
